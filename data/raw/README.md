# Raw Data Sources

The raw Central Bank of Sri Lanka (CBSL) Daily Economic Indicators reports are stored in the `raw_pdfs/` directory in the repository root to maintain direct path continuity for existing scripts.

## Directory Structure
- `raw_pdfs/2020/`: 79 daily indicator PDF bulletins
- `raw_pdfs/2021/`: 233 daily indicator PDF bulletins
- `raw_pdfs/2022/`: 238 daily indicator PDF bulletins
- `raw_pdfs/2023/`: 242 daily indicator PDF bulletins
- `raw_pdfs/2024/`: 240 daily indicator PDF bulletins
- `raw_pdfs/2025/`: 237 daily indicator PDF bulletins
- `raw_pdfs/2026/`: 146 daily indicator PDF bulletins

Total bulletins: **1,415+ daily reports** covering macroeconomic variables, exchange rates, interest rates, equity market indices, and Ceylon Electricity Board (CEB) power generation metrics.
